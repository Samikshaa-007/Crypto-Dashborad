# 🚀 Crypto Live Tracker

A web application built with Node.js and Express that displays live cryptocurrency prices, market caps, and 24-hour trends using the public CoinGecko API. 

## 🛠️ Built With
* **Backend:** Node.js, Express.js
* **Frontend:** EJS (Templating), HTML, CSS
* **API:** [CoinGecko](https://www.coingecko.com/en/api) (Fetched via Axios)

## 💻 How to Run This Code

To run this project locally on your machine, follow these steps:

**1. Clone the repository**
2. Install the necessary packages
Bash
npm install

3. Start the server
Bash
node index.js

4. View the website
Open your browser and navigate to http://localhost:3000
